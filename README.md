# ToothDex RPG v1.0

Refonte progressive : le système de brossage de 120 secondes, limite quotidienne de récompenses, Pokédex, missions, séries et sauvegarde locale sont conservés depuis v0.9.

Nouveautés : logo/icône basés sur l’image fournie par l’utilisateur, mode d’exploration pixel art avec cinq zones de Kanto, déplacements tactiles/clavier, sprite de dresseur en pixel art et collection de personnages débloqués par la progression du Pokédex. Les régions suivantes et leurs personnages sont représentés dans la progression prévue, mais les cinq zones entièrement explorables de cette première version sont celles de Kanto.

Déploiement : remplace les fichiers du site par ceux de ce dossier. Pour Android, copie `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` et `toothdex-logo.png` dans les assets du projet Android avant de relancer GitHub Actions.

# ToothDex PWA

Application web progressive installable sur Android, dérivée du prototype ToothDex.

## Déploiement simple avec GitHub Pages
1. Déposez les fichiers de ce dossier à la racine d'un dépôt GitHub.
2. Dans Settings → Pages, choisissez « Deploy from a branch », branche `main`, dossier `/ (root)`, puis Save.
3. Attendez la publication et ouvrez l'URL Pages sur Chrome Android.
4. Dans Chrome, menu ⋮ → « Ajouter à l'écran d'accueil » ou « Installer l'application ».

Les fichiers `index.html`, `manifest.webmanifest`, `sw.js` et les icônes doivent rester au même niveau. La sauvegarde utilise le stockage local du navigateur. Les sprites Pokémon sont récupérés depuis Internet et ne sont donc pas garantis hors connexion.

Note : il s'agit d'un prototype de fan non officiel. Testez le parcours sur votre appareil avant usage régulier.
